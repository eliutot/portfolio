#about

I'm a high school student in Edgefield County, SC, and a web developer and designer. I build and deploy full-stack applications and design interfaces with a focus on typography, layout, and color.

I trained through ICSA Kuwait in full-stack web development (HTML, CSS, JavaScript, PHP, MySQL, Laravel) and graphic design (Adobe Photoshop, Illustrator, CorelDRAW). I'm currently expanding into systems administration and cloud infrastructure.

The first thing I built was a digital product store in PHP and MySQL, with user auth, product CRUD, and an admin dashboard, from a 5-module spec for my ICSA web dev course. It never sold anything (no payment gateway, no file delivery), but it was the first time I built a full app from a requirements document instead of copying a tutorial.

NJROTC cadet. I run Linux Mint at home and have been building projects since middle school.
