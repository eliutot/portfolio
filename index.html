#about

I'm a high school student in Edgefield County, SC. Been building websites for a few years now, and it stopped being a hobby somewhere along the way.

I trained through ICSA Kuwait in full-stack web development (HTML, CSS, JavaScript, PHP, MySQL, Laravel) and in graphic design (Photoshop, Illustrator, CorelDRAW). Next up is systems administration and cloud infrastructure.

The first thing I built was a digital product store in PHP and MySQL: user accounts, product CRUD, an admin dashboard, from a 5-module spec for my ICSA web dev course. It never sold anything, since there's no payment gateway and no file delivery. Still counts as the first time I built an app from a requirements document instead of copying a tutorial, which is the part that mattered.

NJROTC cadet. Linux Mint at home. I've been taking things apart since middle school, and putting some of them back together.
